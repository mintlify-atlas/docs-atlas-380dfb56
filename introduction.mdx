FC Cañaveral is a complete web platform for managing and showcasing a local football club. It brings together squad data, competition results, a merchandise store, and user accounts — all in one place. Admins can manage every aspect of the club from a dedicated dashboard, while fans can browse the squad, follow the league calendar, and shop for official merchandise.

## Get started

<Steps>
  <Step title="Set up the database">
    Import `servidor/database.sql` into MySQL to create all tables and seed sample data
  </Step>
  <Step title="Start the backend server">
    Run `npm run dev` inside the `servidor/` directory — the API starts on port 5000
  </Step>
  <Step title="Start the frontend">
    Run `npm run dev` inside the `cliente/` directory — the React app starts on port 5173
  </Step>
  <Step title="Log in as admin">
    Use the seeded admin account (`raul@test.com` / `1234`) to access the admin dashboard
  </Step>
</Steps>

  See the [Quickstart guide](/quickstart) for the full setup instructions, including prerequisites and configuration details.
</Note>
