The League Standings API exposes the current league table for the division FC Cañaveral competes in. Results are always returned in ascending position order, so the league leader appears first. The endpoint is public and requires no authentication.

**Base URL:** `http://localhost:5000`

---

## GET /api/clasificacion

Returns all league table entries ordered by `posicion` ascending. No authentication required.

### Response

Returns an array of ranking objects.

<ResponseField name="id" type="number">
  Unique numeric identifier for the ranking entry.
</ResponseField>

<ResponseField name="equipo" type="string">
  Name of the team.
</ResponseField>

<ResponseField name="pj" type="number">
  Number of matches played (partidos jugados).
</ResponseField>

<ResponseField name="puntos" type="number">
  Total points accumulated in the league.
</ResponseField>

<ResponseField name="posicion" type="number">
  Current league position. `1` indicates the table leader.
</ResponseField>

<CodeGroup>

```bash cURL
curl --request GET \
  --url http://localhost:5000/api/clasificacion
```

</CodeGroup>

**Example response (200)**

```json
[
  {
    "id": 1,
    "equipo": "FC Cañaveral",
    "pj": 3,
    "puntos": 9,
    "posicion": 1
  },
  {
    "id": 2,
    "equipo": "CD Móstoles",
    "pj": 3,
    "puntos": 7,
    "posicion": 2
  }
]
```
