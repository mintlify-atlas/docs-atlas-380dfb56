The Matches API provides a complete list of FC Cañaveral's fixtures and results for the season, sorted in ascending date order. The endpoint is public and requires no authentication. Each record includes both scheduling information and — for completed matches — the final score.

**Base URL:** `http://localhost:5000`

---

## GET /api/partidos

Returns all matches ordered by `fecha` ascending (earliest first). No authentication required.

### Response

Returns an array of match objects.

<ResponseField name="id" type="number">
  Unique numeric identifier for the match.
</ResponseField>

<ResponseField name="rival" type="string">
  Name of the opposing team.
</ResponseField>

<ResponseField name="fecha" type="string">
  Date and time of the match in ISO 8601 / MySQL DATETIME format (e.g. `"2024-04-20T12:00:00.000Z"`).
</ResponseField>

<ResponseField name="ubicacion" type="string">
  Venue name where the match is played (e.g. `"Polideportivo Cañaveral"`).
</ResponseField>

<ResponseField name="goles_local" type="number">
  Goals scored by the home side. `0` when the match has not yet been played.
</ResponseField>

<ResponseField name="goles_visitante" type="number">
  Goals scored by the away side. `0` when the match has not yet been played.
</ResponseField>

<ResponseField name="jugado" type="boolean">
  Indicates whether the match has been played. `false` means the fixture is upcoming; `true` means the result has been recorded.
</ResponseField>

<Note>
  When `jugado` is `false`, treat `goles_local` and `goles_visitante` as placeholder zeros rather than a real score.
</Note>

<CodeGroup>

```bash cURL
curl --request GET \
  --url http://localhost:5000/api/partidos
```

</CodeGroup>
