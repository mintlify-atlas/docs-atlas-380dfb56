FC Cañaveral is a full-stack web platform built with a Node.js/Express backend and a React frontend powered by Vite. This guide walks you through every step needed to get a fully working local instance running — from installing dependencies and importing the database schema to logging in with the seeded admin account.

<Steps>
  <Step title="Check prerequisites">
    Before you begin, make sure the following tools are installed on your machine:

    - **Node.js** v18 or later — the runtime for both the backend server and the frontend build toolchain
    - **MySQL** 8.0 or later — the relational database used to store all club data

    Verify your versions:

    ```bash
    node --version
    mysql --version
    ```

    <Tip>If you don't have Node.js installed, download it from [nodejs.org](https://nodejs.org). For MySQL, the community edition is sufficient.</Tip>
  </Step>

  <Step title="Clone the repository">
    Clone the project to your local machine and navigate into the project root:

    ```bash
    git clone https://github.com/raulesteban4/proyecto-futbol-daw.git
    cd proyecto-futbol-daw
    ```

    The repository has two main directories:

    - `servidor/` — Express REST API (port 5000)
    - `cliente/` — React + Vite frontend (port 5173)
  </Step>

  <Step title="Set up the database">
    The `servidor/database.sql` file creates the `proyecto_futbol` database, all required tables, and seeds sample data including the admin user, squad players, products, and league standings.

    Import it into MySQL using the CLI:

    ```bash
    mysql -u root -p < servidor/database.sql
    ```

    You will be prompted for your MySQL root password. Once complete, the database `proyecto_futbol` will be ready with all tables populated.

    <Warning>
      The SQL file drops and recreates all tables on each run. Do not execute it against a database that already contains data you want to keep.
    </Warning>

    If you need to verify the import succeeded:

    ```sql
    USE proyecto_futbol;
    SHOW TABLES;
    ```

    You should see eight tables: `order_items`, `orders`, `players`, `products`, `matches`, `ranking`, `teams`, and `users`.
  </Step>

  <Step title="Configure and start the backend">
    The backend connects to MySQL using the credentials hardcoded in `servidor/index.js`. By default it expects:

    - **Host:** `localhost`
    - **User:** `root`
    - **Password:** `Raul@3306`
    - **Database:** `proyecto_futbol`

    <Note>
      If your MySQL installation uses a different root password, open `servidor/index.js` and update the `password` field in the `db` connection object before starting the server.
    </Note>

    Install dependencies and start the backend in development mode:

    ```bash
    cd servidor
    npm install
    npm run dev
    ```

    The `dev` script runs the server with `nodemon`, which automatically restarts on file changes. The API will be available at `http://localhost:5000`.

    A successful start prints:

    ```
    Conectado a la base de datos MySQL
    Servidor corriendo en el puerto 5000
    ```
  </Step>

  <Step title="Install and start the frontend">
    Open a second terminal window, navigate to the `cliente/` directory, and start the React development server:

    ```bash
    cd cliente
    npm install
    npm run dev
    ```

    The `dev` script runs Vite, which serves the React app with hot module replacement. The frontend will be available at `http://localhost:5173`.
  </Step>

  <Step title="Log in as admin">
    Open your browser and navigate to `http://localhost:5173`. The database seed includes a pre-configured admin account:

    <CodeGroup>

    ```text Credentials
    Email:    raul@test.com
    Password: 1234
    ```

    </CodeGroup>

    After logging in, go to `/admin` to access the admin dashboard. From there you can manage players, update match results and scores, edit league standings, and handle store products and orders.

    <Tip>
      The JWT session token expires after 30 minutes. If you get an authentication error while testing the admin panel, log in again to receive a fresh token.
    </Tip>
  </Step>
</Steps>

## What's available after setup

Once both servers are running you have access to the full platform:

| URL | Description |
|-----|-------------|
| `http://localhost:5173` | Public frontend — squad, fixtures, standings, store |
| `http://localhost:5173/admin` | Admin dashboard — requires the admin account |
| `http://localhost:5000/api/jugadores` | REST API — squad endpoint (no auth required) |
| `http://localhost:5000/api/clasificacion` | REST API — league standings (no auth required) |
